# 글로벌 항공 레이더 (Global Flight Radar)

지도 위에 항공기를 실시간에 가깝게 표시하는 정적 웹앱입니다. 항공기를 선택하면 항로, 기종, 고도·속도 등 상세정보를 하단 시트로 보여줍니다.

## 주요 기능

- **항공기 지도 표시**: Leaflet + OpenStreetMap 위에 항공기 마커를 표시하고, 줌 레벨에 따라 아이콘 크기가 조절됩니다.
- **국적별 색상 구분**: 국적마다 고유한 색으로 표시하며, 한국 국적기는 빨간색으로 강조할 수 있습니다.
- **상세정보 시트**: 항공기를 선택하면 콜사인, 기종, 등록번호, 항공사, 출발·도착 공항, 진행률, 도착 예상 시간, 고도, 지상속도, 방위, 수직속도, 사진을 보여줍니다.
- **접기/펼치기**: 상세정보 시트를 `▼ 접기` / `▲ 펼치기` 버튼 또는 상단 손잡이로 접어 지도를 넓게 볼 수 있습니다.
- **항로 표시**: 출발 공항에서 현재 위치까지 대권항로(지구 곡률을 따르는 경로)를 그립니다.
- **검색 및 필터**: 콜사인·국적 검색, 항공사별 필터(한국, 일본, 중국, 동남아, 중동, 미주, 유럽 등)를 지원합니다.
- **궤적 표시**: 접속 이후 항공기가 이동한 경로를 선으로 보여줍니다.
- **자동 갱신**: 60초마다 데이터를 다시 불러옵니다.

## 동작 구조

```
GitHub Actions (주기 실행)
   └─ OpenSky Network 호출 → flights.json 생성·커밋
          │
GitHub Pages (정적 호스팅)
   └─ index.html ── flights.json 읽기 (같은 저장소라 CORS 문제 없음)
                 └─ api.adsbdb.com 호출 (선택한 항공기의 항로·기체 정보)
```

- 항공기 위치 데이터는 GitHub Actions가 OpenSky Network에서 받아 `flights.json`으로 저장합니다.
- 브라우저는 이 정적 파일만 읽으므로 서버가 필요 없습니다.
- 항로, 기종, 사진은 항공기를 선택할 때 [adsbdb](https://www.adsbdb.com/) API로 조회합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면과 모든 로직이 들어 있는 단일 파일 |
| `flights.json` | GitHub Actions가 주기적으로 갱신하는 항공기 데이터 |
| `README.md` | 이 문서 |

## 사용 방법

1. 지도에서 항공기 아이콘을 누르면 하단에 상세정보가 나타납니다.
2. 지도가 가려지면 시트의 `▼ 접기` 버튼이나 손잡이를 눌러 접습니다. 다시 누르면 펼쳐집니다.
3. 왼쪽 위 `☰` 메뉴에서 항공사 필터, 궤적, 자동갱신, 국적기 강조를 설정하고 항공기 목록을 볼 수 있습니다.
4. 검색창에 콜사인(예: `KAL123`)이나 국적명을 입력하면 해당 항공기를 찾을 수 있습니다.

## 배포 방법

1. 저장소에 `index.html`을 올립니다.
2. GitHub Actions 워크플로로 `flights.json`이 주기적으로 갱신되도록 설정합니다.
3. 저장소 Settings → Pages에서 GitHub Pages를 활성화합니다.

## 참고 사항

- 항로 정보는 콜사인 기반 DB에 등록된 경우에만 표시되며, 없으면 "항로 정보 없음"으로 나옵니다.
- 도착까지 남은 시간은 직선거리와 현재 속도로 계산한 추정치입니다.
- 궤적은 페이지를 연 이후의 데이터만 표시합니다.
- `flights.json`이 아직 생성되지 않았다면 "flights.json 로드 실패" 메시지가 나타납니다.
